# Seyifunmi Christiana — QA Portfolio

A responsive, single-page portfolio website designed for Netlify.

## Before publishing

1. Open `index.html`.
2. Replace `YOUR_EMAIL@example.com` with your real email.
3. Replace the LinkedIn URL with your actual LinkedIn profile.
4. Optionally add your CV link, profile photo, GitHub and other social links.

## Deploy to Netlify

### Option A — Drag and drop
Log into Netlify, choose **Add new project → Deploy manually**, and drag this folder into the deploy area.

### Option B — GitHub
Push this folder to a GitHub repository, then in Netlify choose **Add new project → Import an existing project**, select GitHub and the repository, and publish it.

The site is plain HTML/CSS/JavaScript, so there is no build command required.
